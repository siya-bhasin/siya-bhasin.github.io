Bello!
For this assignment, we had to find an arduino code online that played some music of our choice
and we had to modify the code so that the music would play only when a switch was pressed.
For my code, I chose to play "Never Gonna Give You Up" by Rick Astley. I found it on
https://projecthub.arduino.cc/rowan07/rickroll-piezo-buzzer-b3d9fd (Thank you Rowan Packard!)
As for what I had to do at a high-level to make this code work-- not much. I changed the Buzzer pin's
name and number to match our arduino. The original code had a light that beeped to the beat
of the song and I removed it. As for adding the switch component, I thought the void loop was
very simple to understand, especially since they also used void play and so I could easily
modify their loop to ensure the music only plays when a button is pressed.

A tip I would like to give my past self is to read through the code of the song I chose
and think about how I can modify it instead of modifying a code I wrote around switches to play
the song because the code for some of these songs is really complicated and it's easier to 
figure out how to edit them instead of the other way around.
